Prompt 5 — Enforce relation-over-text principle
---
Looking at the ontology proposal, I want to make sure we are using relations wherever possible instead of storing data as text. Specifically:
- City, state, and country should all be relation properties pointing to entity types (City type, State type, Country type) because each should exist as their own entities.
- League should be a relation to a League entity type, not a text field.
- Any other categorical data that appears in multiple places should follow the same pattern.

Can you update the ontology proposal accordingly, and also make sure we have the City, State, Country, and League types defined?

Prompt 6 — Refine data types
---
A few specific data type decisions I want to nail down:

1. Day game / Night game — let's make this a boolean. True = day game, False = night game.
2. ERA, batting average, fielding percentage — these should be Float64 (decimal).
3. Innings pitched — this should also be Float64. Note: innings pitched in baseball uses base-3 notation (6.2 means 6 and 2/3 innings, not 6.2), so document this convention in the property description.
4. Win probability, leverage index — Float64.

Can you review the full ontology and flag any other properties where the data type choice might need discussion?

Prompt 7 — Finalize naming conventions
---
Let's establish naming conventions for the ontology before we write any files. Here are the rules:
- Only the first letter of the first word should be capitalized, unless it is an acronym (e.g., RBI, ERA, MLB, ID).
- Minor words (prepositions, articles) stay lowercase in the middle of a name: "Runner on 1B", "Top of inning", "Hit by pitch".
- Parenthetical units are capitalized: "Height (inches)", "Weight (lbs)".
- Boolean properties: use positive phrasing without "Is" prefix for official stats (Day game, Game started, Complete game, Save). Use "Is" prefix for state descriptions (Is scoring play, Is designated hitter).

Can you review the full ontology proposal and fix any names that don't follow these conventions? List all the ones you changed.
---
